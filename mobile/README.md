# Zembo Browser — Android (каркас)

## Запуск
1. В пустой папке: `flutter create --platforms=android --org com.zembo zembo_browser_mobile`
2. Замени в созданном проекте `pubspec.yaml` и папку `lib/` на файлы из этого архива.
3. `flutter pub get` → `flutter run`

## android/app/src/main/AndroidManifest.xml
Перед `<application>`:
```xml
<uses-permission android:name="android.permission.INTERNET"/>
```
В тег `<application ...>` добавь `android:usesCleartextTraffic="true"`.

Чтобы браузер можно было выбрать «по умолчанию», в `<activity android:name=".MainActivity" ...>` добавь:
```xml
<intent-filter>
    <action android:name="android.intent.action.VIEW"/>
    <category android:name="android.intent.category.DEFAULT"/>
    <category android:name="android.intent.category.BROWSABLE"/>
    <data android:scheme="http"/>
    <data android:scheme="https"/>
</intent-filter>
```
(Сами ссылки приложение пока не принимает — это отдельный шаг.)

В `android/app/build.gradle` (или `build.gradle.kts`) нужны `minSdk 21` и `compileSdk 34` или выше.

## Что готово
- Тема (чёрный #000000, панели, оранжевый акцент), молния, плитки ярлыков, стартовая страница
- Вкладки (шторка-переключатель), навигация, прогресс загрузки, история
- Верхняя строка: адресная строка → расширения → почта → ⋮
- Блокировщик рекламы по спискам фильтров (HaGeZi, Arkynx), счётчик, обновление списков
- Тёмная тема сайтов (через WebView), полноэкранное видео
- Настройки: поиск, приватность, тёмная тема, пароли, ссылка на GitHub

## Обновление 3 (оптимизация и меню)
- Списки фильтров (≈850 тыс. доменов) теперь хранятся как компактный индекс (~7 МБ вместо сотен МБ), грузятся с диска мгновенно и стартуют через 2 с после запуска.
- Результаты поиска строятся лениво, счётчик блокировок не перерисовывает экран.
- Меню ⋮ открывается снизу: новая вкладка, обновить, копировать ссылку, версия для ПК, история, загрузки, настройки.
- При первом запуске после обновления списки скачаются заново (формат хранения изменился).

## Обновление 4

## Обновление 5
