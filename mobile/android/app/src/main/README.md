# Иконка Zembo Browser

1. Скопируй папку `res` из этого архива в `android/app/src/main/res/` проекта (с заменой файлов).
2. Замени `android/app/src/main/AndroidManifest.xml` на файл из архива (название приложения теперь «Zembo Browser»).
3. Выполни `flutter clean`, затем `flutter build apk --debug` (или `flutter run`).
4. Старое приложение лучше удалить с телефона, иначе лаунчер может показать прежнюю иконку.
